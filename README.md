# MP3-Converter.malt
A Python application for downloading and converting permitted
video sources into MP3 audio.

## Features

- [ ] Download audio from a URL
- [ ] Convert audio to MP3
- [ ] Choose audio quality
- [ ] Display download progress
- [ ] Graphical user interface

## Requirements

- Python 3
- FFmpeg
